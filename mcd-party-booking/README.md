# 麦当劳派对订场助手 · mcd-party-booking

> 把麦当劳**生日派对 / 主题派对 / 亲子读书会**的"选址 → 选期 → 选场次 → 算成本"四步一次跑完。纯只读——不代下单、不代订场。

一个 WorkBuddy Skill，接麦当劳官方 MCP（`https://mcp.mcd.cn`），帮想办线下派对的用户回答 App 里从不集中展示的问题。

## 它解决什么问题

麦当劳在全国大量门店提供生日派对、主题派对、亲子读书会等线下活动，但官方 App 里这些信息分散，**"哪几家店能办、最近可约哪天、当天几个场次、几人成团、多少钱"从不集中展示**。用户只能反复翻 App、打电话问店员。

实测：上海可办派对的门店就有多家（南京东路、南京西路、福州路等），且每天多个场次（如 12:00–13:30、18:30–20:00），成团 5–12 人——这些信息本 Skill 一次拉全。

## 目标用户

- 想给孩子办麦当劳生日派对的家长
- 想组织主题派对 / 亲子读书会的社群主理人
- 需要快速比对"哪天、哪家店、哪个场次"的行政/活动策划

## 三条能力

| 能力 | 用户问什么 | 核心输出 |
|---|---|---|
| 派对场馆选址 | "上海哪能办生日派对" | 城市→门店→日期→场次 四级收敛清单 |
| 派对成本核算 | "办一场多少钱" | 商品价 + 场次价 + 成团人数 + 人均参考 |
| 派对活动日历 | "最近有什么派对" | 当月派对/品鉴会/读书会活动 |

## 安装

1. 申请麦当劳 MCP Token：浏览器打开 `https://open.mcd.cn/mcp/login` → 手机号 + 短信验证码登录 → 右上角【控制台】→【激活】→ 复制 Token
   （注意：`open.mcd.cn` 首页的【登录】与导航【商户平台】是**商户入口**，个人开发者进不去）
2. 在 WorkBuddy 的【连接器】→【自定义连接器】按 `config/mcp-config.example.json` 填入配置，把 `${MCD_MCP_TOKEN}` 换成你的 Token
3. **完全退出 WorkBuddy 再重开**（自定义 MCP 在启动时加载），重开后在【MCP 服务管理】里启用 `mcd-mcp`
4. 复制本 Skill 到技能目录，新建对话即可触发

## 安全边界

本 Skill **全程只读**，仅调用：`now-time-info`、`mall-points-products`、`query-party-city`、`query-party-store`、`query-party-store-date`、`query-party-store-session`、`campaign-calendar`。

**不调用** `party-order-create` 等任何写操作。本 Skill 只做选址、选期、成本参谋；是否下单由用户自行在官方渠道完成。

## 差异化说明

已主动避让同赛道已有作品：

| 已有作品 | 方向 | 本 Skill 的差异 |
|---|---|---|
| `junxchan54-maker/mcd-cn-assistant` | 活动推送 + 比价 | 本 Skill 聚焦**派对线下场地链路**（城市→门店→日期→场次） |
| 积分/营养类 | 积分折算 / 热量 | 本 Skill 不碰积分与营养，聚焦**派对订场决策** |
| 外送链路编排类 | 配送流程自动化 | 本 Skill **不涉及下单**，纯只读选址参谋 |
