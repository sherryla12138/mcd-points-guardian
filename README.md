# 麦当劳积分守门员 · mcd-points-guardian

> 把麦当劳积分的**过期倒计时**和**兑换性价比**算清楚。纯只读——不代下单、不代抽奖。

一个 WorkBuddy Skill，接麦当劳官方 MCP（`https://mcp.mcd.cn`），帮麦麦会员回答三个商城页面不会直接告诉人的问题。

## 它解决什么问题

麦当劳积分有两条容易被忽略的规则：**会静默过期**，且**不同商品的积分价值差 2～5 倍**。

实测同一批积分商品券里，"50 分换 6.9 元派"折算率是 `0.138 元/分`，"200 分换 10.9 元小食"只有 `0.0545 元/分`——**相差 2.5 倍**。而商城页面既不提示到期量，也不告诉你哪档最划算。结果是积分被清零，或花在了最不划算的档位上。

## 目标用户

- 每月有积分到账、但从不关注过期日的麦当劳会员——他们真实存在一笔"看不见的余额损失"
- 手上攒了 200～800 积分，站在积分商城前不知道换哪个最值的人
- 想试积分抽奖，但不确定"24 分一次"值不值的人

## 三条能力

| 能力 | 用户问什么 | 核心输出 |
|---|---|---|
| 到期积分体检 | "我的积分会过期吗" | 本月将清零多少、能换到什么东西 |
| 积分兑换比价 | "积分换什么划算" | 按时效过滤后的**折算率排序表** + 最优推荐 |
| 抽奖成本核算 | "抽奖值不值" | 单次成本换算成现金价值 + 与直接兑换的对比 |

## 安装

1. 申请麦当劳 MCP Token：浏览器打开 `https://open.mcd.cn/mcp/login` → 手机号 + 短信验证码登录 → 右上角【控制台】→【激活】→ 复制 Token
   （注意：`open.mcd.cn` 首页的【登录】与导航【商户平台】是**商户入口**，个人开发者进不去）
2. 在 WorkBuddy 的【连接器】→【自定义连接器】按 `config/mcp-config.example.json` 填入配置，把 `${MCD_MCP_TOKEN}` 换成你的 Token
3. **完全退出 WorkBuddy 再重开**（自定义 MCP 在启动时加载），重开后在【MCP 服务管理】里启用 `mcd-mcp`
4. 复制本 Skill 到技能目录，新建对话即可触发

## 安全边界

本 Skill **全程只读**，仅调用：`now-time-info`、`query-my-account`、`mall-points-products`、`mall-product-detail`、`query-lottery-info`、`query-my-prizes`、`query-my-coupons`。

**不调用**任何写操作：`mall-create-order`、`draw-lottery`、`create-order`、`party-order-create`。涉及消耗积分的动作只做成本核算与建议，是否执行由用户自行决定。

## 差异化说明

已主动避开同赛道已有作品：

| 已有作品 | 方向 | 本 Skill 的差异 |
|---|---|---|
| `junxchan54-maker/mcd-cn-assistant` | 活动推送 + 最优惠比价 | 本 Skill 不做活动推送，聚焦**积分资产时效** |
| 「热麦卡路里」 | 热量估算 + 套餐档位 | 本 Skill 不碰营养数据，聚焦**积分折算率** |
| 外送链路编排类 | 配送流程自动化 | 本 Skill **不涉及下单链路**，纯只读 |
